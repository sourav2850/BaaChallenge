Todo List App
Overview
A simple and interactive Todo List app built with React.js. This app allows users to manage tasks efficiently with features like task creation, editing, deletion, drag-and-drop reordering, filtering, pagination, and more. It also includes a modal to view task details and is designed with enhanced accessibility.

Features
Create, Edit, Delete Tasks: Easily add, edit, or remove tasks to keep your to-do list organized.

Task Completion: Mark tasks as completed or incomplete with a simple click.

Drag-and-Drop: Rearrange tasks easily using the drag-and-drop functionality provided by react-beautiful-dnd.

Task Filtering: Filter tasks by status:

Completed

Incomplete

All Tasks

Pagination: View tasks in pages with a limit of 10 tasks per page.

Task Details: View detailed information of each task in a modal window.

Accessibility: Enhanced for better usability with keyboard support and focus management.

Tech Stack
Frontend:

React.js - JavaScript library for building the user interface.

react-beautiful-dnd - Library for enabling drag-and-drop functionality for tasks.

SCSS - For styling the app with a modern, clean, and responsive layout.
