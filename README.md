Todo List App
Overview
A simple and interactive Todo List app built with React. It allows users to manage tasks, including features like task creation, editing, deletion, drag-and-drop reordering, filtering, and pagination.

Features
Create, Edit, Delete tasks: Easily add, edit, or remove tasks.

Task Completion: Mark tasks as completed or incomplete.

Drag-and-Drop: Rearrange tasks using drag-and-drop functionality.

Task Filtering: Filter tasks by status (Completed, Incomplete, or All).

Pagination: View tasks in pages (10 per page).

Task Details: View task details in a modal.

Accessibility: Enhanced for better usability (keyboard support, focus management).

Tech Stack
React.js

react-beautiful-dnd (for drag-and-drop)

SCSS for styling
